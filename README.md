# 플라즈마 OES 데이터 분석기

플라즈마 OES(광방출분광법) 데이터를 스펙트럼 및 시계열로 시각화하고, Reference Spectrum 대비 현재 시점의 Pearson Correlation Score를 계산하여 표시하는 PyQt5 기반 GUI 프로그램입니다.

## 주요 기능

- **스펙트럼 뷰어**: 특정 시간의 전체 스펙트럼(200-800nm) 시각화
- **시계열 뷰어**: 선택된 파장의 시간에 따른 강도 변화 추적
- **Pearson Correlation 계산**: Reference 스펙트럼 대비 현재 스펙트럼의 유사도 평가
- **파장 하이라이트**: 선택된 파장 영역(±1nm) 강조 표시
- **인터랙티브 UI**: 그래프 클릭으로 시간 선택 및 Reference 설정

## 기술 스택

- Python 3.8+
- PyQt5 (GUI 프레임워크)
- Matplotlib (데이터 시각화)

- NumPy (수치 계산)

## 사용 방법

### 1. 데이터 로드

- 좌측 패널의 **"파일로딩"** 버튼 클릭
- `.dat` 파일 선택 (탭 구분자, UTF-8 인코딩)

### 2. 파장 선택

- 파장1, 파장2, 파장3 입력 필드에 원하는 파장(nm) 입력
- 우측 체크박스로 각 파장의 표시 여부 설정
- 범위: 200.0 ~ 800.0 nm
- 스텝: 0.5 nm

### 3. 시간 탐색

**방법 1: SpinBox 사용**
- "시간 (sec)" SpinBox에서 원하는 시간 선택

**방법 2: 그래프 클릭**
- 하단 그래프(시계열 뷰어)를 클릭하여 시간 선택
- **Shift + 클릭**: Reference Time 설정

### 4. Reference 설정

- "Reference Time (sec)" SpinBox에서 기준 시간 선택
- 또는 시계열 그래프에서 **Shift + 클릭**으로 설정

## 데이터 파일 형식

### .dat 파일 구조

```
Name    Run Time    200.0    200.5    201.0    ...    800.0
A       0.5         1234     1235     1240     ...    890
A       1.0         1250     1260     1255     ...    900
...
```

- **구분자**: 탭 (`\t`)
- **인코딩**: UTF-8
- **열 1**: 센서명 (문자열, 무시됨)
- **열 2**: Run Time (float, 초)
- **열 3~1203**: 파장별 광강도 (200.0nm ~ 800.0nm, 0.5nm 간격, 총 1,201개)

## 알고리즘

### 파장별 Intensity 계산

노이즈 감소를 위해 **target_wavelength ± 1nm 범위의 평균값** 사용:
- 0.5nm 간격이므로 총 5개 포인트 평균 (중심 ± 2 인덱스)

### Pearson Correlation Score 계산

선택된 파장들 주변 **±10nm 범위만** 사용하여 계산:

```
r = Σ(x-x̄)(y-ȳ) / √[Σ(x-x̄)² × Σ(y-ȳ)²]
```

- **x**: Reference 스펙트럼의 선택 영역 값
- **y**: 현재 스펙트럼의 선택 영역 값
- **범위**: -1.0 ~ 1.0
  - 1.0: 완전 양의 상관관계
  - 0.0: 상관관계 없음
  - -1.0: 완전 음의 상관관계

## GUI 레이아웃

### 좌측 컨트롤 패널 (250px)
- 파일로딩 버튼
- 파장 입력 필드 3개 (SpinBox + CheckBox)
- 시간 입력 필드
- Reference Time 입력 필드

### 우측 그래프 영역 (950px)

**그래프 A (스펙트럼 뷰어, 800x220px)**
- X축: Wavelength (nm)
- Y축: Emission Intensity (a.u.)
- 선택된 파장 영역 하이라이트 표시

**그래프 B (시계열 뷰어, 800x220px)**
- X축: Run Time (sec)
- Y축 좌: Intensity (a.u.)
- Y축 우: Correlation Score (-1.0 ~ 1.0)
- 현재 시간: 빨간색 점선
- Reference 시간: 회색 점선 + Correlation 텍스트
